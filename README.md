# Прогнозирование рейтинга отеля на основе отзывов

Данный проект решает задачу **регрессии** — предсказание рейтинга отеля (`reviewer_score`), который посетитель поставит после проживания, на основе его отзыва, демографических данных и информации об отеле.

Модель обучена на данных с платформы [Booking.com](https://www.booking.com/), где пользователи оставляют текстовые отзывы и числовые оценки. Цель — построить точную и интерпретируемую модель, которая может быть использована для анализа факторов, влияющих на удовлетворённость гостей.

---

## 📊 Описание данных

Набор данных включает информацию как об отелях, так и о рецензентах:

| Признак | Описание |
|--------|---------|
| `hotel_address` | Адрес отеля |
| `review_date` | Дата, когда рецензент разместил соответствующий отзыв |
| `average_score` | Средний балл отеля, рассчитанный на основе последнего комментария за последний год |
| `hotel_name` | Название отеля |
| `reviewer_nationality` | Национальность рецензента |
| `negative_review` | Отрицательный отзыв, который рецензент дал отелю |
| `review_total_negative_word_counts` | Общее количество слов в отрицательном отзыве |
| `positive_review` | Положительный отзыв, который рецензент дал отелю |
| `review_total_positive_word_counts` | Общее количество слов в положительном отзыве |
| `reviewer_score` | **Целевая переменная**: оценка, которую рецензент поставил отелю (от 0 до 10) |
| `total_number_of_reviews_reviewer_has_given` | Количество отзывов, которые рецензенты дали в прошлом |
| `total_number_of_reviews` | Общее количество действительных отзывов об отеле |
| `tags` | Теги, которые рецензент дал отелю (тип поездки, состав группы и т.д.) |
| `days_since_review` | Продолжительность между датой проверки и датой очистки |
| `additional_number_of_scoring` | Количество оценок без текстового отзыва |
| `lat` | Широта отеля |
| `lng` | Долгота отеля |

---

## 🧠 Подход

- **Feature Engineering**: извлечение геопризнаков (расстояние до центра, азимут), обработка текста (семантические категории, сентимент-анализ), кодирование национальности и тегов.
- **Моделирование**: использование градиентного бустинга (CatBoost, LightGBM) с оптимизацией под метрику MAPE.
- **Валидация**: стратифицированная кросс-валидация для устойчивой оценки качества.

---

## 🏆 Результаты

Модель достигает **MAPE ≈ 10.5%**, что позволяет достаточно точно предсказывать рейтинг отеля на основе поведенческих и текстовых сигналов.

> 💡 **Примечание**: признаки `average_score` и `additional_number_of_scoring` технически являются *утечками данных* (data leakage), но широко используются в соревнованиях на Kaggle для достижения высоких результатов.
